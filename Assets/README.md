# Wave Spawner

Тестове завдання на позицію Unity Developer у Mind Studios

## Вимоги
- Unity 6000.4.6f1

## Як запустити
1. Відкрийте проєкт у Unity.
2. Відкрийте сцену MainScene за шляхом Game/Scenes/MainScene.
3. Запустіть Play Mode.

## Фічі
- Налаштування WaveSequence через ScriptableObject.
- Підтримка нескінченного режиму.
- Налаштування кількості ворогів, інтервалів їх появи та затримок між хвилями.
- Можливість налаштовувати та додавати нові типи SpawnArea.
- Візуалізація SpawnArea у сцені.
